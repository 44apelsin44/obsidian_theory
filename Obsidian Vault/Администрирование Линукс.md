
команды для администрирования:

1 Сети
route -- таблица маршрутизации IP

nmap  ... -- диагностика сети, аудит бещопасности

traceroute  ...    -- отслеживание исходящего трафика

tracepath -- отслеживание пути до конечной точки с обнаружением MTU 

ping ... -- отправка icmp пакетов на заданный айпи адрес/домен для проверки доступности сервера 

ifconfig -- вывод информации о сетевых интерфесах устройства

nslookup ... -- запрос к днс, возвращает информацию о домене

ip -- назначение адреса сетевому интерфейсу и/или настройки сетевого интерфейса в операционных системах линукс

ssh .. -- протокол, похволяющий производить удалённое управление операционной систмой и туннелирование TCP-соединений

curl .. --  передача данных на сервер или с сервера с использованием любого из поддерживаемых протоколов

scp .. --  безопасное копирование файлов между локальной и удалённой системой по ssh
