`Transmission control protocol`

Транспортный протокол, гарантирующий целостность дставленных данных. Работает медленнее UDP, засчёт проверки целостности и установк соединения

Особенности:
	При потере пакета(клиент не прислал подтверждение получения) пакеты отправляются снова
	Ведёт нумерацию пакетов
	Ограничен по объёму передаваемых данных

Используется в других протоколах, где скорость не критична, по сранению с целостностью

Механизм установки соединения

1 Клиент->Сервер 
SYN Клиент инициирует соединение и отправляет серверу пакет SYN 

2 Сервер->Клиент 
Сервер отвечает, подтвержает подключение и отправляет пакеты SYN+ACK(таже предоставляет информацию по типу какой протокол шифрования данных он использует)

3 Клиен->Сервер 
Клиент подтверждает получение пакетов, отправляя пакет ACK.
